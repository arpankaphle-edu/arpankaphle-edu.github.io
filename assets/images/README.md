# Social Media Images

## og-image.jpg
This directory should contain a `og-image.jpg` file for social media sharing (Open Graph and Twitter Cards).

**Recommended specifications:**
- **Dimensions**: 1200x630 pixels (optimal for most social platforms)
- **Format**: JPG or PNG
- **File size**: < 1MB (ideally < 500KB)
- **Content**: Should include:
  - Your name/branding
  - Professional photo or logo
  - Relevant background or design elements
  - Consider using a tool like Canva or Figma to create

**Why this matters for SEO:**
- Better social media sharing appearance
- Increases click-through rates from social platforms
- Professional presentation across LinkedIn, Twitter, Facebook
- Falls back gracefully if missing (platforms use default sharing behavior)

**To add your image:**
1. Create or design a 1200x630 image
2. Save it as `og-image.jpg` in this directory
3. The HTML files are already configured to reference it
